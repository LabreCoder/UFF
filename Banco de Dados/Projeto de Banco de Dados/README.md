Repositório dedicado aos materiais, anotações, laboratórios e exercícios práticos desenvolvidos na disciplina de **TCC00335 — Projeto de Bancos de Dados** do curso de **Sistemas de Informação** da **Universidade Federal Fluminense (UFF)**.

---

## 📌 Visão Geral do Conteúdo

A disciplina aborda os conceitos avançados e práticos necessários para o projeto físico, otimização e gerenciamento de bases de dados relacionais. O conteúdo progride desde a arquitetura de armazenamento físico de SGBDs monolíticos (Heap Files, Buffer Pool e paginação em disco) e estruturas de indexação (índices primários, secundários, densos, esparsos, Árvores B/B+) até técnicas de parsing, estimativa de seletividade, geração de planos de execução de consultas e controle de concorrência em transações.

## 🛠️ Tecnologias & Ferramentas Utilizadas

* **Linguagem / Tecnologia:** SQL, PL/SQL

* **Sistemas / SGBD:** PostgreSQL, MySQL, Git, GitHub

---

## 💻 Como Executar os Códigos / Projetos

Para clonar e testar os scripts SQL/DDL diretamente via terminal:

```bash
# Navegar até a pasta da aula desejada (Exemplo: Aula_01)
cd Aula_01

# Executar scripts SQL diretamente no cliente PostgreSQL
psql -U usuario -d nome_do_banco -f script.sql
```

> ⚙️ **Requisitos do Ambiente:** PostgreSQL 14+ / MySQL 8.0+ instalado e rodando localmente ou via container Docker.
