## 📌 Visão Geral do Conteúdo

A disciplina aborda os fundamentos teóricos e práticos para a construção de sistemas de software complexos, cobrindo o histórico do desenvolvimento, a crise do software, as características intrínsecas aos produtos de software e a tríade fundamental de processos, métodos e ferramentas. Ao longo do semestre, a matéria avança para a engenharia de requisitos, modelagem de sistemas com UML e boas práticas de desenvolvimento de software.

## 🛠️ Tecnologias & Ferramentas Utilizadas

* **Ferramentas de Modelagem:** UML Diagrams, Visual Paradigm Online, Draw.io / Diagrams.net
* **Ambiente da Disciplina:** Google Classroom
* **Leituras e Materiais:** Livro *Engenharia de Software Moderna*, *Apostila de Orientação a Objetos da Caelum* e Regulamento de Graduação UFF

## 💻 Como Executar os Códigos / Projetos

Para clonar e executar os exercícios diretamente via terminal:

```bash
# Navegar até a pasta da aula desejada (Exemplo: Aula_01)
cd Aula_01

# Compilar / Executar (Ajustar conforme a linguagem/ferramenta)
# Exemplo em Java:
javac src/Exercicio01.java
java -cp src Exercicio01

```
