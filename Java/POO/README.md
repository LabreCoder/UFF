# ☕ Programação Orientada a Objetos (POO) — UFF

Repositório dedicado aos materiais, laboratórios e exercícios práticos desenvolvidos na disciplina de **Programação Orientada a Objetos em Java** da Universidade Federal Fluminense (UFF).

---

## 📌 Módulos do Curso

Java/POO/
├── ⚙️ Módulo 1: Fundamentos & Sintaxe Base (Aulas 01 a 10)
├── 🧩 Módulo 2: Orientação a Objetos & Conceitos Essenciais (Aulas 11 a 16)
└── 🚀 Módulo 3: Tópicos Avançados & Concorrência (Aulas 17 a 19)

---

## 📌 Visão Geral do Conteúdo

O curso é estruturado de forma incremental, partindo dos fundamentos da linguagem (sintaxe, controle de fluxo e arrays) até os pilares da Orientação a Objetos e tópicos avançados como Concorrência e o Framework de Coleções.

## 🛠️ Como Executar os Projetos

Para compilar e executar qualquer código via terminal:

```bash
# Entrar na pasta da aula desejada (exemplo: Aula 03)
cd Java/POO/Aula_03

# Compilar o arquivo .java
javac NomeDoArquivo.java

# Executar a classe gerada
java NomeDoArquivo
```
