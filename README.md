## 📖 Sobre o Projeto

Este espaço funciona como um portfólio acadêmico e de aprendizado contínuo. Aqui estão centralizados os materiais das disciplinas cursadas, listas de exercícios resolvidas, projetos acadêmicos e materiais de apoio produzidos durante atividades de monitoria.

### 🎯 Objetivos

- Documentar a evolução acadêmica e técnica ao longo da graduação.
- Organizar códigos, atividades práticas, trabalhos acadêmicos e relatórios.
- Compartilhar soluções e materiais de apoio com a comunidade acadêmica.
- Facilitar consultas futuras e revisões de conceitos fundamentais da Ciência da Computação / Tecnologia.

---

## 🛠️ Tecnologias e Áreas de Estudo

### 💻 Linguagens & Ferramentas

- **Python**: Resolução de problemas, análise de dados (p. ex. ENEM), redes (Sockets) e materiais de monitoria.
- **C**: Programação de Baixo Nível, Estrutura de Dados I (Aulas, Provinhas e Árvores) e Sistemas Operacionais.
- **Java**: Programação Orientada a Objetos (POO) e Engenharia de Software.
- **SQL & Banco de Dados**: Modelagem ER/Relacional, consultas SQL, Banco de Dados Orientado a Grafos (**Neo4j**).
- **Redes & Sistemas**: Protocolos TCP/UDP, Análise de pacotes com **Wireshark**, Sockets e Sistemas Distribuidos.

### 📚 Disciplinas e Tópicos Presentes

- **Banco de Dados**: Princípios de BD, Projeto de BD, Álgebra Relacional e Neo4j.
- **Redes de Computadores**: Camadas da pilha TCP/IP, Sockets, Labs (DNS, HTTP, Wireshark).
- **Estrutura de Dados I & Prog. II**: Listas, Pilhas, Filas, Árvores (Binária, AVL, B, B+), Tabela Hash e Algoritmos.
- **Sistemas Distribuidos & Sistemas Operacionais**: Comunicação, concorrência e processos.
- **Interação Humano-Computador (IHC)** & **Modelagem de Processos de Negócios (BPM)**.
- **Inteligência de Negócios (BI)** & **Estatística**.

## 🚀 Como Usar

1. **Clone o repositório:**

```bash
git clone [https://github.com/LabreCoder/UFF.git](https://github.com/LabreCoder/UFF.git)
cd UFF
```

2. **Navegação:**

* Navegue até a pasta da disciplina desejada para acessar scripts, aulas e exercícios.

<!--* Na pasta `Monitoria/`, encontram-se exemplos práticos desenvolvidos para atendimento a alunos.-->

3. **Execução de Códigos:**

* **Python:** utilize *python* para rodar no ***Windows*** e *python3* para rodar no ***Linux***.

```Python
python3 Python/Prog\ I/Aula_01_01.py
```

* **C:**

```C
gcc "C/Estrutura de Dados I/Aula_02/exercicio_01.c" -o exercicio
./exercicio
```

## 🤝 Como Contribuir

Sugestões, correções de bugs em exercícios ou melhorias nas explicações são sempre bem-vindas!

1. Faça um **Fork** do projeto
2. Crie uma branch para sua modification (`git checkout -b feature/MinhaMelhoria`)
3. Faça o commit (`git commit -m 'Adiciona resolução do exercício X'`)
4. Envie para o repositório (`git push origin feature/MinhaMelhoria`)
5. Abra um **Pull Request**
